## Ce este Simplicadet
**Simplicadet** este o aplicație web pentru evidență, documente și fluxuri administrative în mediul militar educațional.  
Interfața este rapidă, curată și orientată pe productivitate, cu design unitar în paleta mov a aplicației.

## Funcții cheie
- management prezență pe companii și plutoane;
- generare/export pentru documente și rapoarte;
- secțiune de resurse (inclusiv calculator admitere);
- autentificare și roluri de utilizator;
- interfață modernă cu componente `liquid/glass`.

## Tehnologii
- **Frontend:** React + TypeScript + Vite
- **UI:** Tailwind + componente custom (`liquid`)
- **Backend/API local:** Node.js (scripturi din proiect)

## Cerințe & compatibilitate
- **Sistem de operare:** orice sistem care rulează un browser modern (Windows / Linux / macOS / Android / iOS)
- **Node.js:** 18+
- **npm:** 9+
- **RAM:** minim 4 GB (recomandat 8 GB+)
- **Spațiu liber pe disc:** minim 500 MB
- **Browser:** Chrome / Edge / Firefox / Safari (versiuni recente)

## Pornire rapidă
```bash
npm install
npm run server
npm run dev
```

Aplicația pornește local prin Vite, iar serverul rulează separat pentru endpoint-urile necesare.

## Scripturi
- `npm run dev` — pornește aplicația în development
- `npm run build` — build de producție
- `npm run server` — pornește serverul local
